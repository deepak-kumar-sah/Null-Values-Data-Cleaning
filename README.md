# Null Values Data Cleaning Project

## Project Overview

This project demonstrates how to identify and handle missing values in a dataset using Python, Pandas, and Jupyter Notebook.

## Objectives

* Identify missing values in the dataset.
* Detect and remove completely empty rows.
* Handle missing categorical and numerical values.
* Convert columns to appropriate data types.
* Export the cleaned dataset to Excel and CSV formats.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Jupyter Notebook
* Microsoft Excel

## Data Cleaning Process

1. Loaded the original Excel dataset.
2. Checked missing values in each column.
3. Identified and removed completely empty rows.
4. Filled missing categorical values using the mode.
5. Filled missing numerical values using the median.
6. Converted columns to appropriate data types.
7. Verified that no missing values remained.
8. Exported the cleaned dataset into Excel and CSV files.

## Project Structure

* `data/` — Original and cleaned datasets.
* `notebooks/` — Jupyter Notebook containing the data cleaning steps.

## Output Files

* `cleaned_dataset.xlsx`
* `cleaned_dataset.csv`

## Key Result

The cleaned dataset contains zero missing values after the data cleaning process.

## How to Run

1. Download or clone this repository.

2. Install the required libraries:

   `pip install pandas numpy openpyxl`

3. Open `notebooks/Null_Values_Data_Cleaning.ipynb` in Jupyter Notebook.

4. Run the notebook cells in order.
